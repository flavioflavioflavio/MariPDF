# 📜 MariPDF Manifesto

> *"Software should feel like a superpower, not a chore."*

---

## Nós acreditamos que...

### I. O código pertence a todos. Para sempre.

MariPDF nasce open source e morre open source.
Não existe "versão Pro". Não existe fork fechado. Não existe pivô para SaaS.
O repositório é público, o código é auditável, a história é transparente.
Se o projeto morrer, o código sobrevive. Isso é uma promessa, não uma política.

---

### II. Velocidade não é um detalhe. É respeito.

Cada milissegundo que você espera é tempo que roubamos de você.
MariPDF abre antes de você perceber que clicou.
Roda em hardware antigo sem reclamar.
Não existe "aguarde, carregando...". Apenas: **está pronto**.

Blazing fast não é marketing. É obrigação moral.

---

### III. Zero fricção é o produto.

Abriu. Funcionou.
Sem conta. Sem login. Sem "aceite os termos". Sem tutorial obrigatório.
Sem popup de atualização no meio da leitura.
Sem "deseja definir como leitor padrão?" toda maldita vez.

A menor quantidade de cliques entre você e o seu PDF é sempre a certa.

---

### IV. Beleza e usabilidade são a mesma coisa.

Uma interface feia cansa. Uma interface confusa frustra.
MariPDF é bonito porque respeita o seu tempo e a sua inteligência.
Cada pixel tem propósito. Cada animação tem razão de existir.
O design some e o conteúdo fica — esse é o único objetivo da UI.

Estética não é frescura. É cuidado.

---

### V. Sustentado por gratidão, não por extorsão.

MariPDF é donationware.
Se te economizou tempo, se te ajudou a ler, se simplesmente funcionou bem —
uma doação voluntária mantém o projeto vivo.

Nunca cobraremos. Nunca bloquearemos. Nunca pressionaremos.
A generosidade da comunidade é nossa única fonte de receita,
e isso nos deixa livres para tomar as decisões certas.

---

## O que nunca faremos

- Fechar o código-fonte
- Criar features exclusivas pagas
- Adicionar telemetria ou rastreamento
- Mostrar anúncios
- Vender dados de qualquer tipo
- Fazer o app pesado "só por enquanto"
- Trair a confiança de quem usa

---

## O que sempre faremos

- Manter o repositório público e ativo
- Priorizar performance acima de features
- Tratar cada bug report como uma responsabilidade
- Responder a contribuidores com respeito
- Documentar decisões arquiteturais
- Lançar com changelogs honestos

---

*MariPDF é feito por humanos que leem, para humanos que leem.*
*Nada mais. Nada menos.*
