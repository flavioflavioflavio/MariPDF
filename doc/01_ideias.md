# 💡 MariPDF — Ideias & Visão

> Criado em: 2026-03-22

---

## 🎯 Conceito Central

**MariPDF** é um leitor de PDF para Windows que tem como grande feature ser **extremamente leve** com **abertura instantânea** e **sem frescuras**.

Enquanto o SumatraPDF é tecnicamente excelente mas visualmente está em 2008, o MariPDF une:
- → Performance cirúrgica de um app nativo
- → UI/UX moderna, bonita, premium

---

## 🌟 Diferenciais

1. **Abertura < 200ms** — abre antes do usuário perceber que clicou
2. **UI linda** — não parece software de 2005
3. **Memória mínima** — meta de < 30MB RAM em idle
4. **Zero frescura** — sem telemetria, sem conta, sem cloud, sem popup
5. **Open Source + Donationware** — gratuito para sempre, honesto

---

## 🚫 O que NUNCA terá

- Edição de PDF (fora do escopo por design)
- Telemetria / analytics
- Conta de usuário / login
- Sincronização em nuvem
- Splash screen
- "Deseja definir como leitor padrão?" no startup
- Dialog de confirmação para fechar
- Auto-updater intrusivo
