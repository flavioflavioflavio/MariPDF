# Política de privacidade — MariPDF

*Última atualização: 30 de outubro de 2026*

O MariPDF é um leitor de PDF que funciona inteiramente no seu computador.

- **Nenhum dado é coletado.** O MariPDF não tem telemetria, análise de uso,
  anúncios nem contas de usuário.
- **Seus documentos ficam com você.** Os PDFs são abertos e renderizados
  localmente; nada é enviado para servidores.
- **Dados locais.** Preferências, lista de arquivos recentes, posição de
  leitura e marcadores são gravados apenas no seu computador, na pasta de dados
  do aplicativo. O histórico pode ser limpo nas Configurações (Privacidade).
- **Rede.** A versão da Microsoft Store não acessa a internet. As versões
  baixadas do GitHub só se conectam à API pública do GitHub quando você clica
  em "Verificar atualizações", para consultar a versão mais recente.
- **Links.** Links de documentos e do menu Sobre (GitHub, doação via PayPal)
  abrem no seu navegador e seguem as políticas desses sites.

Dúvidas: abra uma issue em
<https://github.com/flavioflavioflavio/MariPDF/issues>.

# Privacy policy — MariPDF

*Last updated: October 30, 2026*

MariPDF is a PDF reader that runs entirely on your computer.

- **No data is collected.** MariPDF has no telemetry, usage analytics, ads or
  user accounts.
- **Your documents stay with you.** PDFs are opened and rendered locally;
  nothing is sent to any server.
- **Local data.** Preferences, recent files, reading position and bookmarks are
  stored only on your computer, in the app's data folder. History can be
  cleared from Settings (Privacy).
- **Network.** The Microsoft Store version does not access the internet.
  Versions downloaded from GitHub only contact the public GitHub API when you
  click "Check for updates", to look up the latest release.
- **Links.** Links in documents and in the About menu (GitHub, PayPal donation)
  open in your browser and follow those sites' policies.

Questions: open an issue at
<https://github.com/flavioflavioflavio/MariPDF/issues>.
